# Syllabus Topics

Cambridge IGCSE 0478 splits into two papers:

- **Paper 1 — chapters 1–6** (theory)
- **Paper 2 — chapters 7–10** (problem solving, programming, databases, logic)

1. **Data Representation**
   - 1.1 Number Systems
   - 1.2 Text, Sound and Images
   - 1.3 Data Storage and Compression
2. **Data Transmission**
   - 2.1 Types and Methods of Data Transmission
   - 2.2 Methods of Error Detection
   - 2.3 Encryption
3. **Hardware**
   - 3.1 Computer Architecture
   - 3.2 Input and Output Devices
   - 3.3 Data Storage
   - 3.4 Network Hardware
4. **Software**
   - 4.1 Types of Software and Interrupts
   - 4.2 Types of Programming Language, Translators and IDEs
5. **The Internet and its Uses**
   - 5.1 The Internet and the World Wide Web
   - 5.2 Digital Currency
   - 5.3 Cyber Security
6. **Automated and Emerging Technologies**
   - 6.1 Automated Systems
   - 6.2 Robotics
   - 6.3 Artificial Intelligence
7. **Algorithm Design and Problem-solving**
   - 7.1 Computational Thinking Skills
   - 7.2 Algorithms (pseudocode, flowcharts, trace tables)
   - 7.3 Standard Methods of Solution
   - 7.4 Validation and Verification
   - 7.5 Test Data
8. **Programming**
   - 8.1 Programming Concepts
   - 8.2 Arrays
   - 8.3 File Handling
9. **Databases**
   - 9.1 Database Structure
   - 9.2 SQL
10. **Boolean Logic**
    - 10.1 Logic Gates
    - 10.2 Logic Circuits
    - 10.3 Truth Tables
    - 10.4 Logic Expressions

---

The machine-readable version — topic names, what each topic covers, the assessment
objectives and their weightings — is `src/syllabus.py`, condensed from the official
syllabus (`input/0478/0478 Syllabus.pdf`, 2023–2025). The prompt is generated from it.
The official syllabus has no sub-topics in chapters 7, 9 and 10; the codes 7.1–7.5,
9.1–9.2 and 10.1–10.4 above are this project's subdivision.
