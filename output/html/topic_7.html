Q6a 5 marks AO2 Identify 7.2 Algorithms p.4 Paper 2 m25 · QP22 · Q6a▾

This pseudocode algorithm is intended to allow 1000 positive integers to be input and stored in a one-dimensional (1D) array. The integers are added together as they are input and the highest value is identified. At the end of the algorithm, the highest number, the total and the average of the numbers are output.

01 DECLARE Numbers : ARRAY[1:1000] OF INTEGER
02 DECLARE Highest : STRING
03 DECLARE Count : INTEGER
04 DECLARE Total : INTEGER
05 Highest ← 1500
06 Total ← 0
07 FOR Count ← 1 TO 1000
08    INPUT Numbers[Count]
09    Total ← Total + Count
10    IF Numbers[Count] > Total
11    THEN
12       Highest ← Numbers[Count]
13    ENDIF
14 NEXT Count
15 OUTPUT "The highest number is ", Highest
16 OUTPUT "The total is ", Total
17 OUTPUT "The average is ", Average / 1000

Identify the line numbers of five errors in the pseudocode and suggest a correction for each error.

[Contains: pseudocode algorithm]

Marking scheme

One mark per mark point

  • Line 02 / DECLARE Highest : STRING should be DECLARE Highest : INTEGER[1]
  • Line 05 / Highest ← 1500 should be Highest ← 0[1]
  • Line 09 / Total ← Total + Count should be Total ← Total + Numbers[Count][1]
  • Line 10 / IF Numbers[Count] > Total should be IF Numbers[Count] > Highest[1]

01 DECLARE Numbers : ARRAY[1:1000] OF INTEGER

03 DECLARE Count : INTEGER
04 DECLARE Total : INTEGER
05 Highest ← 1500
06 Total ← 0

11    THEN

13    ENDIF

16 OUTPUT "The total is ", Total
